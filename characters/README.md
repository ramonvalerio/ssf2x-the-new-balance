# Personagens

Cada personagem tem uma pasta com `new/` (versão Super) e `old/` (versão antiga, selecionável no SSF2X). Cada alteração entregue fica numa subpasta própria dentro da versão correspondente, com ZIP, IPS, `LEIA-ME.txt` e `verification.json`. O `README.md` de cada personagem lista as alterações e aponta para a spec.

As ROMs são cumulativas: a entrega mais recente inclui todas as anteriores. A ROM que está em uso no Fightcade é sempre a da última entrega.
