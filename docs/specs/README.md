# Specs — mudanças de gameplay

Cada arquivo descreve **uma** mudança de balanceamento/gameplay a ser aplicada na ROM: comando novo/alterado, condições, o que fica preservado, e como testar depois de pronta.

Decisões de abordagem técnica (como a mudança é implementada em termos de engenharia reversa/ferramentas) ficam em `docs/adr/`, não aqui.

Formato: `NNNN-titulo-curto.md`. Status possíveis: `Proposto`, `Em andamento`, `Entregue` (com link para a pasta correspondente em `characters/`), `Descartado`.
