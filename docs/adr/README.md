# ADR — Architecture Decision Records

Decisões técnicas relevantes para o projeto de modificação da ROM de Super Street Fighter 2X (ssf2xjr1), com foco em balanceamento de personagens.

Cada ADR documenta uma decisão de abordagem técnica (não uma mudança de gameplay específica — isso fica em `docs/specs/`), o motivo de tê-la tomado e as alternativas descartadas.

Formato de arquivo: `NNNN-titulo-curto.md`, numeração sequencial, nunca reaproveitada mesmo se um ADR for superado (nesse caso ele é marcado como `Status: Superado por ADR-XXXX`).
